# Vidéo de démo du MVP

`demo-site-app-hd.webm` (1920×1200, environ 79 s, WebM VP9) : le parcours complet site → app → site.

1. Le site (carte interactive de l'équipe) : Marc voit une zone sale.
2. La fiche de la zone renvoie vers l'app.
3. L'app (téléphone) : Léa choisit un pseudo, prend la photo avant, la photo après, publie.
4. Le feed affiche l'avant / après ; la zone passe au vert.
5. Retour sur le site : la même zone est verte, la fiche montre l'avant / après. Une seule base (Supabase) pour les deux.

Lire la vidéo : Chrome, Firefox, Ego ou VLC (QuickTime ne lit pas le WebM).
Lien direct : https://github.com/WHenrypro/generation-zero-dechet/raw/mvp/docs/demo-site-app-hd.webm
