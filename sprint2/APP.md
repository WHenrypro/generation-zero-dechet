# L'app au sprint 2

Le sprint 2 est consacré au signalement sur le site (US21). Pour l'app, ce sprint sert à préparer le terrain :

- découpage du MVP en un site (carte, signalement) et une app (concept BeReal : avant / après, feed), avec les mêmes données ;
- couche de données commune (`commun/js/store.js`, mode local dans le navigateur, mode Supabase prévu) ;
- charte graphique commune au site et à l'app.

Le code de l'app commence au sprint 3 : voir `sprint3/app/`.
